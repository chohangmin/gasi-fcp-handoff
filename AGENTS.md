# Editing workflow

- The active cut is the most recent Final Cut Pro project XML shared by the editor. Use the V2.4 timeline only as the baseline until the first XML is shared.
- Preserve the original MOV and the V2.4 reference export. Keep edits in versioned outputs.
- Use the source timecodes in `timeline/` to match material to the original MOV. Check changes in output time against the relevant project version.
- Store camera originals, audio, review exports, Final Cut libraries, and render caches under local or shared media storage.
- Record cut, dialogue, graphics, and audio changes in `CHANGELOG.md`.
